# salary-prediction-linear-regression
A beginner-friendly Linear Regression model that predicts salary based on experience, publications, and PhD status.

## Dataset Used
This project uses a small, manually created dataset representing:

- Experience (years)
- Publications (count)
- PhD status (1 = yes, 0 = no)
- Salary (in thousands)

The dataset contains 12 samples and is used to train a Linear Regression model.
